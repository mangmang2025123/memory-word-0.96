# Word Memory Assistant (单词记忆助手) Chrome 扩展

您是否在浏览网页时经常遇到新的英文单词，希望有一种简单的方法能把它们记下来，并帮助您巩固记忆？Word Memory Assistant (单词记忆助手) 就是为此设计的！

这款友好的 Chrome 扩展能让您轻松地：

*   **在网页上高亮显示您想要学习的英文单词。**
*   **将这些单词保存到您的个人词汇列表中。**
*   **当您再次访问任何网页时，已保存的单词都会被自动高亮显示，时刻提醒您，加深记忆。**

通过这种方式，Word Memory Assistant 帮助您在日常浏览中不知不觉地学习和巩固英语词汇，让记忆单词变得更加轻松高效。现在就开始构建您自己的词汇表吧！
