# Word Memory Assistant (单词记忆助手) Chrome 扩展

您是否在浏览网页时经常遇到新的英文单词，希望有一种简单的方法能把它们记下来，并帮助您巩固记忆？Word Memory Assistant (单词记忆助手) 就是为此设计的！

这款友好的 Chrome 扩展能让您轻松地：

*   **在网页上高亮显示您想要学习的英文单词。**
*   **将这些单词保存到您的个人词汇列表中。**
*   **当您再次访问任何网页时，已保存的单词都会被自动高亮显示，时刻提醒您，加深记忆。**

通过这种方式，Word Memory Assistant 帮助您在日常浏览中不知不觉地学习和巩固英语词汇，让记忆单词变得更加轻松高效。现在就开始构建您自己的词汇表吧！

## 安装指南 (Installation Guide)

您可以选择以下任一方式来安装 Word Memory Assistant 扩展：

**1. 从 Chrome 网上应用店安装 (推荐方式)**

*   (如果扩展已发布到 Chrome 网上应用店)
*   打开 Chrome 浏览器，访问 [此处填写Chrome网上应用店链接]() (通常我们会提供一个直接链接)。
*   点击 “添加到 Chrome” (Add to Chrome) 按钮。
*   在弹出的确认对话框中，点击 “添加扩展程序” (Add extension)。
*   安装完成后，扩展的图标会出现在浏览器工具栏中。

**2. 手动安装 (适用于开发者或本地安装包)**

如果您拥有扩展的源文件文件夹 (例如，从 GitHub 下载的)，您可以按照以下步骤手动安装：

*   **步骤 1: 打开扩展管理页面**
    *   在 Chrome 浏览器的地址栏输入 `chrome://extensions` 并按回车键。
    *   或者，您可以点击浏览器右上角的三个点菜单 (⋮)，选择 “更多工具” (More tools)，然后选择 “扩展程序” (Extensions)。

*   **步骤 2: 启用开发者模式**
    *   在打开的扩展管理页面右上角，找到并打开 “开发者模式” (Developer mode) 的开关。

*   **步骤 3: 加载已解压的扩展程序**
    *   启用开发者模式后，页面左上方会出现一些新的按钮。点击 “加载已解压的扩展程序” (Load unpacked) 按钮。
    *   在弹出的文件选择对话框中，找到并选择包含 Word Memory Assistant 扩展所有文件的文件夹 (例如，名为 `Word-Memory-Assistant-main` 或类似的文件夹)。
    *   点击 “选择文件夹” (Select Folder) 按钮。

*   **步骤 4: 完成安装**
    *   如果一切顺利，Word Memory Assistant 扩展会出现在您的扩展列表中，并且其图标会显示在浏览器工具栏上。

安装完成后，建议您刷新正在浏览的网页，或重启 Chrome 浏览器，以确保扩展功能正常运行。

## 如何使用 - 快捷键操作 (How to Use - Hotkey Operations)

使用 Word Memory Assistant 非常简单，主要通过键盘快捷键来操作。

**1. 激活操作:**

首先，将您的鼠标光标移动到网页上您想要进行操作的任意英文单词上方。

**2. 快捷键通用规则:**

当鼠标光标悬停在目标单词上时，**按住**相应的数字快捷键约 **0.5 秒** (半秒钟) 后松开，即可触发对应功能。如果按键时间过短，操作可能不会被执行。

**3. 各快捷键功能详解:**

*   **数字键 `2` (默认样式 / 切换移除):**
    *   **如果单词未保存:** 添加该单词到您的词汇列表，并应用默认的红色高亮样式。
    *   **如果单词已保存且当前为绿色或下划线样式:** 将其样式更改为默认的红色高亮。
    *   **如果单词已保存且当前为默认样式:** 从您的词汇列表中移除该单词 (相当于关闭高亮)。

*   **数字键 `3` (绿色样式):**
    *   **如果单词未保存:** 添加该单词到您的词汇列表，并应用绿色高亮样式。
    *   **如果单词已保存但当前不是绿色样式:** 将其样式更改为绿色高亮。
    *   **如果单词已保存且已是绿色样式:** 不执行任何操作，并会提示您该单词已经是绿色。

*   **数字键 `4` (下划线样式):**
    *   **如果单词未保存:** 添加该单词到您的词汇列表，并应用下划线样式。
    *   **如果单词已保存但当前不是下划线样式:** 将其样式更改为下划线样式。
    *   **如果单词已保存且已是下划线样式:** 不执行任何操作，并会提示您该单词已经是下划线。

*   **数字键 `5` (移除单词):**
    *   **如果单词已保存:** 无论当前是什么样式，都将其从您的词汇列表中移除。
    *   **如果单词未保存:** 不执行任何操作，并会提示您该单词不在列表中。

每次操作成功后，页面上通常会显示一条简短的提示信息，告知您操作结果。通过这些快捷键，您可以高效地管理您的个性化词汇表，并根据记忆程度调整单词的样式。

## 弹窗界面功能 (Popup Window Features)

您可以通过点击浏览器工具栏上的 "Word Memory Assistant" 图标来打开扩展的弹窗界面。这个界面是您管理词汇列表的控制中心。

弹窗界面提供以下主要功能：

*   **查看单词列表 (View Word List):**
    *   清晰展示所有已保存的英文单词。
    *   每个单词旁边会显示其当前的高亮样式（例如：默认红色、绿色、下划线）。
    *   列表会按字母顺序排列，方便查找。

*   **单词数量统计 (Word Count):**
    *   在界面显眼位置实时显示您词汇列表中的总单词数量。

*   **移除单个单词 (Remove Individual Words):**
    *   列表中的每个单词旁边都有一个“移除”按钮。
    *   点击此按钮可以从您的词汇列表中删除特定的单词。

*   **清空所有单词 (Clear All Words):**
    *   提供一个“清空所有”按钮，允许您一次性删除列表中的全部单词。
    *   通常，在执行此操作前会有一个确认提示，以防误操作。

*   **导出单词 (Export Words):**
    *   通过“导出单词”按钮，您可以将整个词汇列表（包括单词及其样式信息）下载为一个 JSON 格式的文件 (`wordlist.json`)。
    *   这方便您备份或在不同设备间迁移您的词汇数据。

*   **导入单词 (Import Words):**
    *   通过“导入单词”按钮，您可以选择一个之前导出的 JSON 文件，将其中的单词和样式信息导入到扩展中。
    *   导入功能会覆盖当前的词汇列表。请注意备份您现有的列表（如果需要）。

*   **刷新列表 (Refresh List):**
    *   提供一个“刷新列表”按钮，可以手动重新加载并显示当前最新的单词列表。

*   **快捷键使用说明 (Hotkey Instructions):**
    *   弹窗界面通常会包含一个简要的快捷键使用指南，提醒您如何在网页上通过键盘快捷键（如 '2', '3', '4', '5'）来添加、修改样式或移除单词。

通过这些功能，您可以方便地维护和管理您的个性化英语词汇表。
