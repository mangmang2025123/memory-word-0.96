Word Memory Assistant - Help & Instructions

General Usage

The Word Memory Assistant helps you learn new words by highlighting them on webpages. You can save words, assign different visual styles, and manage your list through the popup window.

Hotkey Operations

To use hotkeys, hover your mouse cursor over a word on any webpage and then press and hold the corresponding numeric key for about 0.5 seconds.

  • Key 2 (Default/Red Style):
    • If word is unsaved: Adds word with default red highlight.
    • If word has a different style: Changes style to default red.
    • If word is already default red: Removes the word from your list.
  • Key 3 (Green Style):
    • If word is unsaved: Adds word with green highlight.
    • If word has a different style: Changes style to green.
    • If word is already green: No change (message shown).
  • Key 4 (Underline Style):
    • If word is unsaved: Adds word with underline style.
    • If word has a different style: Changes style to underline.
    • If word is already underlined: No change (message shown).
  • Key 5 (Remove Word):
    • If word is saved: Removes it from your list.
    • If word is unsaved: No action (message shown).
  • Key 6 (Blue Highlight): Applies blue highlight. (Behavior: Add if unsaved, change style if saved, message if already this style).
  • Key 7 (Yellow Background): Applies yellow background. (Behavior: Add if unsaved, change style if saved, message if already this style).
  • Key 8 (Bold Text): Applies bold text. (Behavior: Add if unsaved, change style if saved, message if already this style).
  • Key 9 (Italic Underline): Applies italic underline. (Behavior: Add if unsaved, change style if saved, message if already this style).

Popup Window Features

Click the extension icon in your browser toolbar to open the popup window. From here, you can:

  • View Word List: See all your saved words, their current style, and the date they were added.
  • Change Styles: Use the buttons next to each word (2, 3, 4, 6, 7, 8, 9, A, B, C, D) to change its style.
  • Delete Words: Click button 5 next to a word to remove it.
  • Popup-Only Styles: Styles A, B, C, and D can only be applied using their respective buttons in this popup window. They do not have hotkeys.
    • A: Light grey background, dark text.
    • B: Dark slate background, light text.
    • C: Pale yellow background, brown text/border.
    • D: Light pink background, dark magenta text, monospace font.
  • Manually Add Words/Phrases: Type a word or short phrase (letters and spaces only) into the input field and click "Add Word". It will be added with the default red style.
  • Search: Use the search box to filter your word list.
  • Sort: Choose a sort order for your list (Alphabetical or Time Added). This preference is saved.
  • Import/Export: Save your word list to a file or load a list from a file.
  • Clear All: Remove all words from your list (confirmation required).
  • Refresh List: Manually reload the list from storage.
